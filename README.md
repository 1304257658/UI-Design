# UI Design 研究项目

本项目用于研究：**如何使用 AI 生成视觉效果好、有创意、可以落地的前端 UI 设计。**

## 当前课题

- [DeepSeek Harness 架构拆解页](http://127.0.0.1:8770/)：面板侧转、插件展开、工具往返、粒子回流与回答回显；[实现、来源与验收](./ai-ui-design/experiments/004-deepseek-harness/README.md)。

- [Anime.js 首页复刻](http://127.0.0.1:8769/) 与 [时间轴教学实验](http://127.0.0.1:8769/study/)：机械拆解、滚动叙事与引擎机制；[踩坑、源码和验收记录](./ai-ui-design/experiments/003-anime-homepage/README.md)。

- [打开 2D 界面图鉴](http://127.0.0.1:8768/)：五个分类、36 个可操作样本。本地服务运行时有效；[源码与说明](./ai-ui-design/learning/ui-atlas-2d/README.md)。

- [AI 前端 UI 设计研究](./ai-ui-design/README.md)：课题范围、研究方法与文档入口。

## 工作约定

- 使用子文件夹隔离课题与实验，避免不同方案相互覆盖。
- 讨论中形成的判断、决策、实验结果和经验同步到项目文档。
- 区分待验证假设、单次实验观察和可复用经验；不把工具宣传或主观印象当作已验证结论。
- 具体工具的能力、限制与用法，在实际研究时核对官方资料并记录来源和日期。
