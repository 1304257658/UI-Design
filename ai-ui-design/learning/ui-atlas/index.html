把“那个感觉”，
变成设计语言。

不用先学写代码。换一种外观、点开一个组件，
你就能把想要的界面描述给 AI。

Aa风格

看懂，比背术语更重要。

先分清这四件事
风格 穿什么衣服
布局 内容摆在哪里
组件 用什么方式操作
状态 操作后如何回应

“玻璃风格的右侧抽屉”完全说得通：一个描述外观，一个描述交互。
