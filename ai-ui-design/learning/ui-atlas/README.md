# UI 词汇实验室 · 第一册

面向只有少量 HTML/CSS 认识的学习者，以“看见 → 操作 → 说清楚”的方式建立与 AI 沟通的 UI 词汇。

## 打开方式

直接用现代浏览器打开 [index.html](./index.html)，无需安装依赖或构建。

如需本地 HTTP 预览，在此目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765`。这是本机预览，不是已部署的网站；关闭服务器后该地址不再可用，文件仍可直接打开。

## 建议的第一次体验

1. 在“视觉风格”里切换玻璃、极简、新粗野，观察同一张卡片的变化。
2. 回到玻璃风格，把背景模糊调到 0，再调高；然后改变白底不透明度。
3. 在“交互组件”里依次打开抽屉、模态弹窗、底部面板，比较出现位置和关闭方式。
4. 对比气泡卡片与文字提示：前者可以含操作，后者主要提供简短说明。
5. 在“说给 AI 听”里组合外观、布局和交互，编辑并复制生成的需求。

无需一次记住全部名词；先能辨认、能描述，再逐步掌握细节。

## 内容与边界

- 六种风格：玻璃、极简、新粗野、新拟物、杂志编辑、赛博科技。
- 四种布局：便当盒、等分卡片网格、侧栏、分屏。布局区域为结构示意，不是完整业务页面。
- 八种组件：抽屉、模态弹窗、底部面板、气泡卡片、文字提示、轻提示、折叠面板、标签页。
- 四组状态：骨架屏、空状态、错误状态、悬停/按压/聚焦。
- 需求组合器与概念辨认练习。

风格名称是常用标签，边界并不统一；示例只展示一种典型表达。页面不连接后端，不实际保存笔记或收藏。底部面板不支持拖拽。折叠面板使用原生 details，无展开动画。剪贴板不可用时会选择文本并提示手动复制。

实现为 HTML、CSS 与原生 JavaScript，无外部字体、图片、脚本依赖。外部链接仅用于查阅参考资料。

## 参考资料

核对日期：2026-09-17。下面的资料支持组件行为、可访问性与背景模糊的说明，不为六种视觉风格提供统一分类。

- [Ant Design：Drawer](https://ant.design/components/drawer/)：边缘滑入的面板、详情与编辑场景。
- [Ant Design：Popover](https://ant.design/components/popover/)：附着在触发元素附近、可以包含操作的浮层。
- [Ant Design：Message](https://ant.design/components/message/)：操作后的轻量反馈。
- [W3C APG：Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)：模态行为、焦点循环、Esc 和焦点恢复。
- [W3C APG：Tooltip](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)：悬停和聚焦提示；该模式页面注明仍在完善。
- [MDN：backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)：处理元素背后的区域，需要透明或半透明表面才能看到效果。
