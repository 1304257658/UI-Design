# 收藏馆交互方案 · 讨论稿

日期：2026-09-17。视觉参考已确认：最初的方向 1 原稿。更新：用户已提出尝试 WASD 自由漫游，取代下文最初的点选式推荐作为当前实验方向；两厅早期原型已运行，但视觉被用户判定差距过大，完整交互未验收。以下保留初次讨论提案，不代表全部已实现。最新状态见 [WASD 实验](../../experiments/002-sunlit-museum/README.md)。

## 核心体验

全景发现 → 点选展品 → 镜头靠近 → 动手体验 → 收藏与表达。

用户可以随意选择展品，也能通过上一件、下一件连续参观。每次靠近都必须有明确的返回入口。

## 默认建议：点选式参观

- 入馆直接呈现用户选定的晴天展厅视角，保留原稿光线。
- 默认镜头静止，允许非常轻微、有限的观察角度调整；不自动巡航，不随鼠标持续晃动。
- 鼠标移到展品上，展签浮现名称和“点击体验”，轮廓轻微强调；手机上直接点击，键盘也有等价入口。
- 点击展品或展签后，镜头移动到预设的舒适观看位置。过渡暂以约 0.8 秒为原型起点，实际体验再调，不视为固定指标。
- 镜头停稳后再进入操作状态。快速连续点击只响应最终目标，避免多个过渡叠加。
- 上一件 / 下一件在相邻观察位之间移动；返回展厅恢复进入前的视角和选中状态。
- 减少动态效果时直接切换或使用短淡入淡出。

## 一个具体的玻璃展品体验

1. 用户在原稿相同的展厅中看到中央玻璃展台。
2. 点击玻璃展品，镜头靠近，展品调整到适合阅读与操作的正面角度；周围仍能看到部分展厅。
3. 右下角原有说明牌扩展为暖白阅读面板，显示“玻璃风格 / Glassmorphism”、一句解释和三个特征。
4. 用户拖动“背景模糊”滑块，展品立即变化；拖动“不透明度”观察不同效果。提供恢复默认按钮。
5. 点击“怎么描述”，展示与当前设置对应的中文需求，例如“半透明白底、明显的背景模糊、细亮边框，正文清晰”。
6. 点击收藏，保存该展品及所选参数，并给出简短确认。返回展厅后，展签保留小型收藏标记。

原型实现时要验证：玻璃效果的变化来自示例面板本身；背景、光照和文字均可辨认。材质观察与文字阅读需要协调，不能让眩光遮住教学内容。

## 展品操作如何区分

| 展品类别 | 主要动作 | 说明内容 |
| --- | --- | --- |
| 风格 | 调节关键参数，观察同一内容的视觉变化 | 名称、可见特征、用途、描述示例 |
| 布局 | 切换内容排布与视口模式 | 主次、分区、手机适配 |
| 组件 | 点击真实按钮体验开关、提示或切换 | 触发位置、是否阻止背景、如何关闭 |
| 状态 | 模拟等待、成功、空内容、失败与恢复 | 当前状态与下一步 |

近景中保持少量固定操作：“动手试”“看讲解”“怎么描述”。这三项是展品近景的内容切换，不占用全景主导航。

抽屉与模态弹窗在独立的示例界面范围内演示，并标明示例边界。讲解面板和“返回展厅”仍然能找到。“阻止背景操作”的教学指示针对示例应用中的背景，不混淆整个收藏馆的导航。

## 讲解与返回

- 主讲解使用清晰、面向屏幕的阅读层，色彩和材质呼应原稿的暖白说明牌。
- 大段讲解不贴在远处墙面，不要求用户放大浏览器才能读。
- 打开收藏册时保留展厅当前状态；关闭后回到原观察位置。
- Esc 按层级关闭：先关闭当前演示弹层，再关闭当前阅读浮层，再返回全景。一次按键只处理最上层。
- 拖动滑块、选择文字、操作组件时，镜头不接收同一手势；滚动讲解内容不推动场景。

## 收藏如何有用

- 每件收藏保存名称、类别、当前参数、一句描述和可选备注。
- 收藏册支持重新体验、移出收藏、复制单件描述。
- 后续从风格、布局、组件三个维度组合收藏，形成完整需求描述。
- 第一版建议本机保存，不增加登录流程；用户数据不会自动跨浏览器或设备同步，应在收藏册中说明。

## 默认范围，不需要用户逐项决定

- 桌面作为主要参观体验，手机保留单展品浏览与全部核心学习操作。
- 场景保持原稿的自然光感；环境微动只作为轻微点缀，默认不自动播放声音。
- 建立清晰的键盘焦点、关闭/返回入口、资源加载反馈与渲染失败时的文字浏览入口。
- 首轮先做一个展厅、少量展品和完整的体验收藏流程，再扩展藏品数量。
- 测试关注镜头舒适度、命中准确性、展品文字可读性和交互反馈，不能仅靠静态截图验收。

## 真正需要确认的偏好

**参观方式：**

- 推荐：点选式导览。点击玻璃展台后，镜头自动到合适位置；点击下一件继续参观。
- 可选：自由漫游。用户通过方向键或 WASD 在馆内行走，控制朝向，自己走到玻璃展台附近再点选。

这会影响空间规模、移动控制和首版范围。后续用户已提出尝试 WASD 自由漫游；容量采用模块化主题展厅与目录定位方案探索。其余内容作为可调整的提案，视觉还原优先于继续扩展。
