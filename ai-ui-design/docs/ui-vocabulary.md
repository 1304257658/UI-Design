# UI 词汇：先能说清楚，再学实现

本课题当前优先学习目标：建立学习者与 AI 的认知对齐。前端经验按入门水平安排，不要求先掌握框架或组件库。

当前交互教材：[2D 界面图鉴](../learning/ui-atlas-2d/README.md)，包含材质与风格、交互模式、粒子与 3D、组件动画、数据与图表五个分类，共 36 项。下文保留第一册的基础词汇框架，运行方式、最新验证记录与资料来源见新图鉴说明。

## 四个描述维度

| 维度 | 回答的问题 | 示例 |
| --- | --- | --- |
| 视觉风格 | 看起来是什么气质、材质？ | 玻璃风格、极简、新粗野 |
| 页面布局 | 内容放在哪里、主次怎样安排？ | 便当盒、侧栏、左右分屏 |
| 交互组件 | 用户通过什么界面零件操作？ | 抽屉、弹窗、Tabs |
| 状态与动效 | 等待、点击、失败时如何回应？ | 骨架屏、错误状态、轻微上浮 |

“玻璃风格的右侧抽屉”包含两个维度。“模态”表示打开时阻止背景交互，不是“居中”的同义词。本教材中的右侧抽屉就是模态的。[W3C 模态对话框说明](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)

## 第一册词汇清单

| 名称 | 英文 | 看什么、试什么 |
| --- | --- | --- |
| 玻璃风格 | Glassmorphism | 半透明面板与背景模糊 |
| 极简 | Minimalism | 留白、有限配色、清晰主次 |
| 新粗野 | Neubrutalism | 粗描边、硬阴影、大胆色块 |
| 新拟物 | Neumorphism / Soft UI | 同色表面、两侧柔影、凸起感 |
| 杂志编辑风 | Editorial Design | 标题、分隔线、阅读节奏 |
| 赛博科技风 | Cyberpunk / Futuristic UI | 深底、荧光点缀、网格；只是其中一种变体 |
| 便当盒布局 | Bento Grid | 大小模块组成规整网格 |
| 等分卡片网格 | Card Grid | 等宽卡片与重复结构 |
| 侧栏布局 | Sidebar Layout | 一侧导航，另一侧主内容 |
| 分屏布局 | Split-screen Layout | 两个主要内容区域并置 |
| 抽屉 | Drawer | 从边缘滑入的面板 |
| 模态弹窗 | Modal Dialog | 关闭前背景不可操作 |
| 底部面板 | Bottom Sheet | 从底部出现，常用于触屏界面 |
| 气泡卡片 | Popover | 靠近触发点，可以包含操作 |
| 文字提示 | Tooltip | 简短补充说明，悬停或聚焦显示 |
| 轻提示 | Toast / Message | 操作后的短暂反馈 |
| 折叠面板 | Accordion / Disclosure | 原位展开、收起内容 |
| 标签页 | Tabs | 同一区域切换并列内容 |
| 骨架屏 | Skeleton | 数据到来之前的结构占位 |
| 空状态 | Empty State | 没有内容及下一步指引 |
| 错误状态 | Error State | 失败说明与恢复入口 |
| 悬停、按压、聚焦 | Hover / Active / Focus | 输入操作对应的视觉反馈 |

风格词属于常见设计表达，而非严格标准。同一个词可能被不同人用于不同变体。组件术语也会随设计系统变化，因此最好同时描述实际行为。

## 可以直接套用的表达

> 我要做一个【页面用途】。整体采用【风格】，具体表现为【配色、材质、边框、阴影】。内容使用【布局】。当用户【操作】时，出现【组件、位置、是否遮罩、关闭方式】。成功、等待、无内容和失败时分别给出反馈。手机端采用【适配方式】。

例如：

> 做一个个人灵感收藏页。卡片是磨砂玻璃质感：半透明白底、背景模糊、细亮边框。首页使用大小错落的便当盒布局。点击卡片后，从右侧打开详情抽屉，背景加遮罩，支持关闭按钮和 Esc。手机端卡片改为单列。正文清晰，动效轻微。

不知道术语时，也可以描述“从哪里出现、遮不遮住背景、里面能不能点、怎样关闭”，再让 AI 帮忙命名。术语用于减少歧义，不是沟通的门槛。

## 后续学习顺序

1. 先体验本册，建立视觉与名字之间的对应关系。
2. 再学视觉参数：字体、字号层级、字重、行高、间距、圆角、阴影、描边。
3. 再学配色与整体气质，把“温暖”“冷静”“活泼”翻译为可观察的设计选择。
4. 最后回到 AI 生成实验，比较不同描述方式的产出与迭代成本。

以上是教学安排；哪种学习方式最有效、哪种 AI 方法最好，仍需实际反馈和实验验证。
