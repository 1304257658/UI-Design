# AI 前端 UI 设计研究

创建日期：2026-09-17

我们研究的目标是：找到一套可重复使用的方法，让 AI 产出有视觉品质、有创意且适合实际使用的前端 UI，并保留足够的过程证据来解释结果。

当前阶段：**完成 DeepSeek Harness 真实架构的滚动拆解原型，等待用户整体体验；保留图鉴与 Anime.js 复现，尚未开展 AI 工具对比实验。**

## 先回答哪些问题

1. **设计方向从哪里来？** 需求描述、参考图、设计约束、视觉素材分别起什么作用？
2. **创意怎样产生并保留下来？** 怎样探索多个方向，怎样选择，怎样避免迭代后变得平庸或失去一致性？
3. **设计怎样落地？** 视觉稿转成前端后，排版、字体、素材、动效和交互是否保持质量？
4. **怎样评价和复现？** 哪些效果来自方法，哪些可能只是一次幸运生成？质量提升需要多少时间与人工干预？

## 后续如何记录

- 每次有实质讨论，在讨论记录中追加日期、问题、观点、决定与待办。
- 决定改变研究范围或实验方式时，同步修改研究方案。
- 开始实验后，在独立目录保存提示词、工具/模型信息、代码和浏览器截图等证据。
- 经验库只收录有实验依据的结论；未经实验的想法保留在研究方案中。
- 结论被新证据推翻时，保留旧记录并注明修订原因。
