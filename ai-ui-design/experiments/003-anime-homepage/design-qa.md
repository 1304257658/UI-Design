验收日期：2026-09-18。范围：公开首页本地复现，以及独立教学实验。没有复制官方文档站、后台服务或缓动编辑器。

- Source visual truth：[原站](https://animejs.com/)，逐段采集桌面/手机全页，原始截图与 `source-layout.json` 位于 [证据目录](../../docs/evidence/anime-replica/)。
- Implementation：http://127.0.0.1:8769/ ，通过 Codex 浏览器实际打开、操作和截图。
- 桌面 CSS 视口：1280×720；原站与本地对应截图均为 1265×712 像素。
- 手机 CSS 视口：390×844；原站与本地对应截图均为 375×812 像素。
- 工具导出的图像略小于 CSS 视口；每组来源与实现采用相同导出方式、相同像素尺寸。组合图不对其中一侧单独缩放，不把窗口/滚动条裁切差异算作页面差异。
- 另一次直接用 CDP 改设备尺寸导致本地截图缩放异常，已恢复并弃用该次截图，改用实际浏览器 viewport 设置重采。
- 时间状态：首屏 y=0；Learn more 后稳定 y=2160；拖动段 y=8640。连续循环的曲线和局部零件存在相位差，不做像素完全相等声明。

## 五个保真面

1. **字体与排版**：保留原站 DINish、Berkeley Mono；桌面标题字号、三行结构、正文换行和手机两行标题与来源一致。教学页中文使用系统字体回退，非原站英文标题比较对象。
2. **间距与布局**：首屏主体大小、文字位置、底部 CTA、拆解标注与菜单宽度一致。桌面整页高度 16,913 px；手机 20,041 px，与原站观察一致。手机全页检查未出现页面横向溢出。
3. **颜色与材质**：暗色背景、模块强调色、浅色拆解背景、发光轮廓和代码配色保留。背景与材质切换通过原站时间轴驱动。
4. **素材与图像**：22 个 GLB、真实 logo/图标、字体和依赖均本地化；没有用 CSS 造型替代首页机械装置。重新检查观察到的资源清单，外域页面资源为零；手机扫至页尾后图片加载失败数为零。
5. **文案与内容**：首页内容保留；有意修改浏览器标题、社交元数据和订阅成功提示，明确本地演示。赞助名单是采集快照，顺序可能与原站动态排序不同。

## 交互与运行验证

- Learn more：源站和本地均到达 y=2160 的拆解阶段。
- 页面滚动：桌面和手机扫完整页；检查主题切换、功能段、模块组合与页尾。
- 进度条：点击后跳转到相应场景，观测到 y=8059；继续移动到 y=8640 检查拖动。
- 绿色圆盘：实际拖动并释放，DOM transform 出现位移与回弹，模型演示保持响应。
- 手机菜单：展开、关闭，页面保持手机布局。
- 文档导航：所有文档 href 指向官方域名；本地 `/documentation` 链接残留数为零。没有将未复制页面伪装成已实现的本地路由。
- 复制：实际点击，复用了原站剪贴板实现及反馈；自动化 clipboard 读回为空，原站相同。因此没有宣称完成系统剪贴板内容的端到端验证。
- 表单：使用保留测试域名的演示邮箱，提交显示本地提示，不触发原站请求或保存邮箱。
- 教学页：跳帧 4500ms 显示 75%、60px、54.6°、透明度0.50；播放、倒放、倍速、缓动切换和归零经过浏览器操作。手机 outBack 峰值附近重新检查布局。
- 教学引擎：6/6 Node 测试通过；构建通过。单测覆盖确定性跳帧、调度去重、反向与倍速、暂停、帧率独立性、无效输入和销毁。
- 控制台：教学页无观察到的 error/warn；首页出现过与原站一致的包围球 NaN 警告，列为已知限制。资源导入错误已修复，不将历史日志误报为当前新增错误。

## 限制与后续

- 尚未定位原站几何 NaN 的根因；没有隐瞒或过滤该日志。
- 快速跨段和旧标签重载时，上游代码卡可能残留；这是观察到的原站行为，本实验未重写该状态机。
- 首页继承持续动画，未制作完整 reduced-motion 替代版；教学页默认暂停且后台暂停。
- 未做 Safari/Firefox、触摸真机、低端 GPU、长时功耗、完整键盘/读屏审计。不能将模拟手机视口测试称为手机真机性能验证。
- 单纯库字节数不包括完整站点成本；约 5.3 MB 原始本地资源独立列在清单中。
- 剩余剪贴板读回限制如上，不以截图替代该项证明。
