# 动效实验验证

Date: 2026-09-17

final result: passed

验证对象：局部动效复刻与独立实验控制器，非原站整页像素级克隆。

## 已执行

- Chrome 真实页面渲染：桌面默认视口 2167 × 1144、手机覆盖视口 390 × 844。
- 原站视觉与加载脚本：確認 Three.js r180、实际 32,000 点、参数化混合形态、消息曲线条带与 DOF。
- 桌面视觉：白色点云具备连续流动的轮廓、前后虚实、细红弧线与变红节点；调整点云占屏比例后复核。
- 手机视觉：倾斜构图、12,000 点、控制器换行；修正初版点云偏小问题。390 px 视口下文档宽 375 px，无横向溢出。
- 暂停/继续：按钮 aria-pressed 和状态文案同步，画面停止/恢复。
- 重新开始：暂停时重置可见点云并清除红线、节点感染状态；继续后恢复传播。
- 点云/传播线开关：分别隔离两个图层，全部关闭时画面为空。
- 景深开关：同一暂停帧下，关闭后点云恢复清晰颗粒；开启后有明显深度模糊。
- 速度滑块：键盘 ArrowRight 从 1.00× 更新到 1.25×。
- reduced-motion：通过 Chrome 媒体仿真核实，加载后按钮为“播放”、aria-pressed=true。已移除仿真和临时视口覆盖。
- 渲染控制台：观察到的 error/warn 记录为空。
- npm run build：通过。单入口 bundle 约 544 kB，gzip 约 138 kB；Vite 有超过 500 kB 的体积提示，不是构建失败。

## 边界

- 本次未做帧率基准、真机 GPU 兼容性矩阵、长时间压力测试或 WebGL 上下文丢失测试。
- 本地保留 3 个消息槽位，简化原站级联调度与取景算法，消息节奏更快。
- 未实现原站文章滚动淡出、浅色主题或 SVG fallback。
- 截图只证明所捕获帧的视觉；动画控制和状态另通过实际操作验证。
