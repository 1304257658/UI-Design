每厅六件是此次陈列密度的选择，不是浏览器或 3D 世界的容量上限。新增风格可以进入其他主题厅，目录支持直接定位，减少长距离走路。目前只制作两厅；按距离加载/释放展厅、资源预算和大量藏品性能测试尚未实现。
