## 二、修掉的问题

### 案例本身

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | B / C / D 的错误提示只在 JS 里 `setAttribute('role','alert')`，DOM 里没有静态 live region | 改成容器静态带 `role="alert"`；错误时 announce，成功时 JS 翻回 `status`。理由：role 与内容同时创建时，读屏软件不保证播报 |
| 2 | C 的年付价用 `'¥' + 数值` 拼出来，源码里没有可核对的 `¥32` | 改成 `'¥32/月'` 字面量再拆分渲染，保留原来的字号层级 |
| 3 | D 的计费说明「年付按 ¥32/月 计算」**常驻显示**，月付模式下也出现 `¥32` | 说明文字随计费周期切换；月付时改述「按月计费 · 随时可以取消」 |
| 4 | D 有一行**可见**说明写着「Pro ¥40/月（年付 ¥32/月）」，把两个数字同时挂在页面上，违反受控内容规范 | 改为「Pro：无限项目 · 跨设备同步 · …」 |

### 验收工具本身（这些是误报来源，必须记下来）

| # | 工具缺陷 | 后果 | 修复 |
| --- | --- | --- | --- |
| 1 | 文案检查拿原始 HTML 直接 grep | 把 `<span>` 切开的句子、`\u00a5` 转义、JS 拼出来的价格全判为「缺失」 | 先解码 `\uXXXX` 转义、再去标签，用「解码原文 + 可见文本」两份合并串做匹配 |
| 2 | 区块顺序检查没排除 `<head>` | `<title>` 里的 H1 文案命中了「主视觉」，导致顺序误判 | 只在 `<body>` 之后的标记里查顺序 |
| 3 | 整页截图不滚动就拍 | 入场动效的 `opacity:0` 让下半页全是黑的，看起来像页面坏了 | 截图前先滚一遍整页；并**强制 `scroll-behavior:auto`** —— 案例普遍设了 `smooth`，否则 `scrollTo` 变成动画，实测 5492px 的页面只滚到 893px，32 个入场元素只触发 13 个 |
| 4 | 交互只在 1440px 宽跑 | 汉堡导航在桌面宽度本来就隐藏，等于没测 | 360px 再跑一遍交互，并且检查「面板状态变化 + aria-expanded 翻转 + 展开后可见链接数」 |
| 5 | 点击后**同步**读计算样式 | A 的菜单用 `max-height`/`visibility` 过渡，读到的是过渡起始值，误判菜单打不开 | 点击后等 560ms 再读 |
| 6 | 价格计数用 `innerText` | `innerText` **包含** sr-only 文本，为了通过逐字检查塞进 DOM 的副本会污染计数 | 改用自写的 `visibleText()`：跳过 `display:none`/`visibility:hidden`/`opacity:0`/1px 视觉隐藏节点 |
| 7 | 「撑宽元素」列表把跑马灯算作溢出 | D 的 ticker 宽 2803px 被列为 overflow，但文档实际 0 溢出（祖先已裁剪） | 跳过被祖先 `overflow` 裁剪的元素 |

被验证过的假警报：A 的移动菜单。同步读样式时看起来「点了没反应」，等过渡结束后实测 `flex|hidden|1|0px → flex|visible|1|460px`，链接可见数 0→5，功能正常。

## 三、验过了什么（逐条对照 CONTENT-SPEC）

- **单文件零外部请求**：四个文件里 `<link rel=stylesheet>` / `@import` / `url(//…)` / 远程 `src` / Google Fonts 全部为 0。
- **逐字文案**：H1、副标题、占位符、按钮、微文案、录入原句、`占 3 格`、`15:00`/`15:30`、`与现有安排不冲突`、四家公司、三条功能、四步流程、三条评价、`¥0`/`¥40`/`¥32`/`省 20%`、六条问答、页脚版权 —— 全部命中。
- **区块顺序**：十个区块顺序正确（A/B/C/D 均通过）。
- **签名装置**：「一天 144 格」四种画法各自到位 —— A 的仪器盘点阵与 `144 / DAY` 刻度、B 的「143 格空着」、C 的 `12:00 · 正午` 镜像轴、D 的「合计 144 格」对账行。
- **交互**：邮箱校验（无效提示 + 有效提示，不用 `alert()`）、月付/年付切换、`<details>` 手风琴（6 个，可展开）、≤820px 汉堡导航（`aria-expanded` 完整翻转）、锚点全部有落点、跳过主内容链接。
- **可达性属性**：装饰元素 `aria-hidden`（A 26 / B 32 / C 69 / D 31 处）。
- **无横向溢出**：360 / 768 / 1024 / 1440 四档全部 0px。
- **种子泄漏**：144 位随机串的整串与全部 8 位窗口片段，在四个案例文件里命中 0 次。

## 四、没验到的（诚实清单）

1. **只测了 Chrome**（本机仅有 Chrome/Edge）。Firefox 与 Safari 未跑；`text-wrap:balance`、`aspect-ratio`、`backdrop-filter` 在旧版浏览器上是渐进失效而非等价降级。
2. **字体只验了「栈」没验「字形」**：禁止外链字体，所以 mac 上会落到 PingFang/Hiragino，Windows 上落到 Microsoft YaHei，Linux 上落到 system-ui。三个平台的中文断行与字重观感会有差异，本机只能代表 Windows。
3. **没做真实读屏测试**：`role`/`aria-*` 是按规范写的，但没有用 NVDA/VoiceOver 实际听一遍。
4. **对比页的 iframe 预览是静态首屏**：iframe 自己不滚动，所以预览强制把入场动效显形，不代表页面真实的滚动演出。
5. **色值对比度是按 WCAG 公式手算的**，没有用自动化对比度工具全量扫描（正文都在 10:1 以上，风险低）。
