# 十分 Tenth · 受控内容规范

四个案例（A/B/C/D）共用本文件定义的产品、文案、区块顺序与交互。
**只有视觉语言和版式结构可以不同** —— 文案、数字、区块顺序一个字都不改。这样横向比较才成立。

## 产品

**十分（Tenth）**：把一天切成 **144 个十分钟格子**的效率应用。
你说一句话，它替你算出这句话要占几格、该落在今天的哪一格。

核心事实（四个案例都要能看出来，但**呈现方式各随其方向**）：

- 一小时 = 6 格，一天 24 小时 = **144 格**
- 一次录入会先被解析成「截止时间 / 项目 / 预计时长」，再折算成**占几格**
- 排期结果一定带具体时间点与是否冲突

## 固定文案（逐字使用）

**H1**：一天 144 格，你想留下什么

**副标题**：随手记一句，十分自动找出时间、项目与时长，把它放进今天最合适的那一格。

**表单**：占位符 `your@email.com` · 主按钮「免费开始」 · 微文案「无需信用卡，30 秒就能排好今天」

**快速录入演示**

- 输入：`周五前把课程大纲发给陈老师 #课程 @30分钟`
- 解析结果：截止 4 月 18 日 周五 · #课程 · 预计 30 分钟 · **占 3 格**
- 排期结果：今天 15:00–15:30（与现有安排不冲突）

**社会证明**：砂丘工作室 · 恒温实验室 · 八分仪 · 蓝湖教育

**功能**

1. **一句话录入** — 输入「明天上午联系王工确认设备清单 #项目A」，十分自动识别截止时间、项目与时长，并折算成要占用的格子数。
2. **十分钟粒度排期** — 以 10 分钟为一格，把任务放进当天真正空着的格子里，不跟会议撞车。
3. **每周复盘** — 自动生成完成率、延期项与时间去向，看清哪些格子一直在被推迟。

**工作流程（四步）**

1. **随手记** — 想到什么就打一行字，不用选项目，不用填表单。
2. **自动整理** — 解析时间、项目与预计时长，算出这句话要占几格。
3. **放进格子** — 结合空闲时段和优先级，落到具体的十分钟格子。
4. **每周复盘** — 看完成率和延期情况，调整下周的节奏。

**用户评价**

1. 林楠 · 产品设计师：「以前光整理待办就要花半小时，现在我只管记。第一次看清时间到底去哪了。」
2. 周凛 · 自由开发者：「手机上记一句，回到电脑前它已经排进格子了，不用再想『这个什么时候做』。」
3. 苏珊 · 内容负责人：「团队共享清单之后，跨时区交接再没丢过事情。」

**价格**

- 免费版 ¥0：个人使用 · 无限任务 · 3 个项目 · 手机与网页同步
- Pro：无限项目 · 跨设备同步 · 日历双向同步 · 团队共享清单 · 每周复盘报告
- Pro 的价格由月付/年付切换控制，**同一时刻只显示一个数字**：
  - 月付选中时显示 `¥40/月`
  - 年付选中时显示 `¥32/月`
  - **不要**写成「¥40/月（年付 ¥32/月）」这种把两个数字同时挂在页面上的形式；

**常见问题（六条）**

1. 和别的待办应用有什么不同？ — 多数工具让你自己整理，十分把「安排」这一步替你做完。
2. 「十分钟一格」会不会太死板？ — 格子只是尺子，不是牢笼。任务可以跨格，也可以随时挪。
3. 支持哪些设备？ — 网页、iOS、Android，实时同步。
4. 数据能导出吗？ — 随时导出为 Markdown 或 CSV，包含全部任务与标签。
5. 离线能用吗？ — 能，恢复网络后自动合并，不丢改动。
6. Pro 可以退款吗？ — 14 天内无理由全额退款。

## 必须实现的功能（每个案例都要有）

- **邮箱表单**：带 `novalidate` 的表单，JS 校验邮箱；无效时在表单附近显示错误提示，有效时显示成功提示，**不要用 `alert()`**。错误提示要有 `role="alert"`。
- **价格切换**：月付 / 年付按钮切换价格文本，切换后 Pro 只显示 **¥40/月** 或 **¥32/月**（不得同时出现两个数字）。原生 JS 即可。
- **FAQ 手风琴**：用 `<details>` / `<summary>`。
- **移动端导航**：≤820px 收起为汉堡按钮，可展开收起，带 `aria-expanded` / `aria-controls`，被控元素有对应 `id`。
- **全局**：锚点链接真的能跳到对应区块；交互元素可键盘操作；纯装饰元素加 `aria-hidden="true"`。
- 起始处提供「跳到主要内容」链接。

## 技术约束

- **单文件、完全自包含**：CSS 写在文件内 `<style>`，JS 写在文件内 `<script>`。
- **禁止任何外部依赖**：不得出现 `http://`、`https://`、`//cdn`、外链 `<link rel=stylesheet>`、Google Fonts、图标库、`@import`、远程图片。
  只能用**系统字体栈** + 内联 SVG 或 CSS 图形。
- 字号只在 `html` / `:root` 上用 `clamp()`；**不要**用纯 `vw` 设置 `letter-spacing` / `margin` / `padding` / `width` / `height` / `gap`（`clamp()`/`calc()` 里出现 vw 可以）。
- 在 **360 / 768 / 1024 / 1440px** 四个宽度下都不能出现横向溢出。
- 尊重 `prefers-reduced-motion`。
- `<html lang="zh-CN">`。

## 底部方向切换器（四个文件都必须一模一样地包含）

用 `<style>` + `<div>`，**不要用 `<a>`**，切换靠 JS 读当前文件名：

```html
<style>
#wf-switch{position:fixed;z-index:9999;right:16px;bottom:16px;display:flex;gap:6px;padding:6px;border-radius:999px;
  background:rgba(16,18,22,.9);border:1px solid rgba(255,255,255,.16);backdrop-filter:blur(10px);
  font:600 12px/1 system-ui,sans-serif;box-shadow:0 8px 24px rgba(0,0,0,.28)}
#wf-switch div{cursor:pointer;padding:7px 11px;border-radius:999px;color:rgba(255,255,255,.66);user-select:none}
#wf-switch div[aria-current="true"]{background:#fff;color:#111}
#wf-switch span{color:rgba(255,255,255,.5);align-self:center;padding:0 3px}
</style>
<div id="wf-switch" role="group" aria-label="切换设计方案">
  <div data-case="a">A</div><div data-case="b">B</div><div data-case="c">C</div><div data-case="d">D</div>
</div>
<script>
(function(){
  var cur=(location.pathname.split('/').pop()||'a.html').replace('.html','').toLowerCase();
  var box=document.getElementById('wf-switch');
  Array.prototype.forEach.call(box.querySelectorAll('[data-case]'),function(b){
    var on=b.getAttribute('data-case')===cur;
    b.setAttribute('aria-current',on?'true':'false');
    b.addEventListener('click',function(){ if(!on) location.href=b.getAttribute('data-case')+'.html'; });
  });
})();
</script>
```

## 关于「144 格」这个装置

四个案例都应该让访客**看见**"一天是 144 个格子"这件事，但画法必须各自不同：

- A 把它画成一台**仪器**（点阵 / 刻度 / 可读的密度）
- B 把它画成**大片的空**（留白即资产，只点亮极少几格）
- C 把它画成**以正午为轴的镜像结构**（左右对称）
- D 把它画成**表格 / 账页**（带编号、状态、汇总）

不要四个都用同一种"点阵网格"。这是四个方向之间最重要的差异点之一。
