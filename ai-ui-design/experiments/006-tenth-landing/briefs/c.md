# 案例 C · 中轴（Axis）

> 认领的线索：字符串的正中心在 **索引 72**，前后两半共用几乎同一套字符 ——
> 但它**镜像对称位置命中 0 / 72**，也就是它**完全不对称**。
> 立场：完美的对称不存在，但人**可以站回中间**。

一句话：一个不跟你较劲的效率应用。

## 定位

暖、软、有人味。像清晨的木质桌面、一本手感好的笔记本。
用**严格的中心对称结构**表达"平衡"，但允许细节不完全对称 ——
因为真实的一天本来就不对称，重要的是有一条可以回来的轴。

**不要**做成"圆角卡片 + 大插画 + 糖果色"的消费级模板（那是 005 的 C 做过的事）。
这里的暖是**克制的陶土与橄榄**，不是高饱和糖果色。圆角有，但统一且不大（14px）。

## 色板

| 角色 | 值 | 说明 |
| --- | --- | --- |
| 页面底 | `#F8F2E7` | 暖砂纸 |
| 面 | `#FFFBF4` | 比底色更亮一点的纸 |
| 线 | `#E0D3BF` | 1px 分隔线 |
| 正文 | `#2B2620` | 对比度 ≈13:1 |
| 次级文字 | `#6E6454` | 对比度 ≈5.3:1 |
| 强调（陶土） | `#B25339` | 主 CTA / 关键数字。对比度 ≈5.5:1 |
| 副色（橄榄） | `#4F6B50` | 已完成 / 正向状态。对比度 ≈5.4:1 |
| 柔光 | `#EBDCC6` | 径向光晕、极淡的底 |

规则：陶土是主色，橄榄是"完成"的语义色。**不要**引入第三个彩色。

## 字体

```
--sans: "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Hiragino Sans GB", system-ui, sans-serif;
--serif: "Source Han Serif SC", "Noto Serif SC", "Songti SC", Georgia, serif;
```

- **H1**：`--sans`，`font-weight: 500`（**不要**超粗），`clamp(2.2rem, 5.4vw, 4.2rem)`，`line-height: 1.28`，`letter-spacing: .01em`。
- **区块标题**：`--sans`，`500`，`clamp(1.55rem, 3vw, 2.5rem)`。
- **正文**：`--sans`，`clamp(0.98rem, 1.05vw, 1.1rem)`，`line-height: 1.9`。
- **衬线只做点缀**：引文、大号数字（价格、时间）、wordmark。
- 圆角：卡片 14px，按钮 999px（胶囊），输入框 12px。三个值固定，不要再加。

## 「144 格」装置（C 的画法：**以正午为轴的镜像**）

在首屏下方放一条**镜像格带**：

- 144 格排成 **12 行 × 12 列**，但视觉上以第 6/7 行之间（正午）为**水平轴**分成上下两半，
  上半 `00:00–12:00`，下半 `12:00–24:00`，两半**形态镜像**。
- 正中一条横向的`1px`轴线上标注 `12:00 · 正午`，两端各一个小菱形。
- 格子的状态：
  - 已排期 = 陶土实心（约 10–14 格），
  - 已完成 = 橄榄实心（约 6–9 格），
  - 空 = `#FFFBF4` 底 + `1px #E0D3BF` 描边。
- **刻意制造一处不对称**：整体镜像，但让其中 2 格颜色"错位"（例如上半有一格橄榄在下半对应位置是空）。
  这处不对称**不加注释**，是给留心的人看的细节。
- 上方一行小字：`00:00 — 24:00 · 一天 144 格`；下方一行：`留白由十分替你看着`。
- 格带整体有**极缓慢的呼吸**（`opacity` 在 .92–1 之间，6s，`ease-in-out`，无限循环）。

## 各区块的处理（顺序不可变）

1. **导航**：单行。左 wordmark 用 `--serif`「十分」+ 小字 `Tenth`；中间锚点链接；右陶土胶囊 CTA。
   ≤820px 收成汉堡，展开面板是从顶部展开的暖砂面板，圆角只在底部两角（14px）。
2. **主视觉**：见上。
3. **快速录入演示**：**左右镜像的两栏**，中间由竖轴分隔：
   - 左栏「你说的」：输入原句，放在一个 14px 圆角、`#FFFBF4` 底、1px 边框的框里，等宽字体。
   - 中间竖轴上放一个陶土小圆点作为"转化"的标记，上方小字 `十分`。
   - 右栏「它懂的」：解析结果三行 + `占 3 格` 的陶土小标签，下方是排期结果
     `今天 15:00–15:30`（衬线大字）+ `与现有安排不冲突`（橄榄色 + 小对勾）。
   - 窄屏时上下堆叠，竖轴变成水平分隔线。
4. **社会证明**：一行四家公司名，居中，之间用 `·` 分隔，上下各一条 1px 短线收边（左右对称）。上方小字 `他们也在用十分`。
5. **功能**：**三栏等宽**，每栏顶部一个**大号衬线序号**（`01 02 03`，陶土色，`clamp(1.8rem,3vw,2.6rem)`），下面标题 + 说明。
   栏与栏之间用 1px 竖线分隔（不用卡片阴影）。每栏配一个圆润的内联 SVG 图形（`stroke:#B25339` 或 `#4F6B50`，`stroke-width:1.6`，`stroke-linecap:round`）。
6. **工作流程**：**2×2 网格**，四格尺寸略有差异（例如第一格稍大），每格是 14px 圆角面 + 1px 边框，左上角一个陶土小圆点编号。
7. **用户评价**：一条大引言在上（衬线，居中，宽度收窄），下方两张小卡片并排（第三张单独居中在下面一行，制造轻微不对称）。
8. **价格**：两个半径 14px 的卡片并排，**Pro 卡更宽**（约 1.15 : 1），Pro 卡顶部有一条 3px 陶土边。
   月付/年付切换做成**暖砂底胶囊分段控件**，居中放在价格区标题下方。
   年付时切换控件右侧出现一个小字「省 20%」，Pro 卡价格显示 `¥32/月`。
9. **常见问题**：每条是一张独立的 14px 圆角卡片（`#FFFBF4` + 1px 边框），`<details>`，`summary` 左侧一个小圆点。
10. **页脚**：居中三段：品牌（衬线大字）/ 链接一行 / 版权小字；上方一条 1px 线，竖轴在页脚中央再做一次短轴线收尾。

## 动效

- 元素的进入：`opacity 0→1` + `translateY(14px→0)`，`420ms`，`cubic-bezier(.22,.61,.36,1)`（**比 A 慢且更软**）。
- 格带的呼吸循环；卡片 hover 时 `transform: translateY(-2px)` + 边框色变深，`200ms`。
- 按钮 hover 时轻微放大 `scale(1.02)`。
- `prefers-reduced-motion: reduce`：关闭呼吸、位移与放大，只保留颜色变化。

## 明确不要做的事

- **不要深色**（整页必须是暖浅色）。
- 不要点阵网格（A）、不要表格（D）、不要大字留白海报（B）。
- 不要高饱和糖果色、不要彩色纸屑、不要渐变按钮。
- 不要超粗字重 —— 这一版的性格是"不跟你较劲"，字要稳，不要喊。
