# 案例 D · 台账（Ledger）

> 认领的线索：**117 个字母里藏着 27 个数字**（27 = 3³），十个数字一个不少，
> 大写比小写多（67 : 50）。数字**藏在字母中间**。
> 立场：效率的真相是**对账** —— 每一格都要能说清去了哪里。

一句话：把一天当成一本要平账的账本。

## 定位

饱和、高能、数据感、略带工业与复古电报味。
整页是**一张印在群青色纸上的对账海报**：超大数字、硬边表格、走马灯数据条。
访客应该觉得"这东西把我的时间算得清清楚楚"。

**不要**做成常见的"深色数据大屏"（黑底 + 荧光绿折线图）。
这里的底色是**明亮饱和的群青**，靠**白 + 品红 + 冰蓝**做层次，不用黑底。

## 色板

| 角色 | 值 | 说明 |
| --- | --- | --- |
| 页面底 | `#2222C4` | 群青，全站主色场 |
| 深 | `#0A0A24` | 文字 / 深色块。在白底上对比度 ≈19:1 |
| 白 | `#FFFFFF` | 群青上的正文，对比度 ≈10:1 |
| 品红 | `#FF2E8B` | 关键高亮、CTA 底、强调块 |
| 冰蓝 | `#7FE6FF` | 次级数据、表格线（在群青上） |
| 淡紫 | `#B9B9F0` | 群青上的次级文字，对比度 ≈4.9:1 |
| 纸白 | `#F2EDE4` | 少数"贴上去的纸条"块 |

对比度规则（重要）：
- **品红 `#FF2E8B` 上的文字只能用 `#0A0A24`**（对比度 ≈5.4:1）。品红**不能**直接放在群青上当小字用（只有 2.9:1）。
  品红在群青上只允许做**大面积色块/图形**，或 ≥32px 的显示级文字。
- 群青上的正文一律 `#FFFFFF`；次级文字用 `#B9B9F0`。

## 字体

```
--sans: "Inter", "Archivo", "Segoe UI Variable Display", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
--mono: ui-monospace, "Cascadia Mono", "SF Mono", "Consolas", "Songti SC", monospace;
```

- **H1**：`--sans`，`font-weight: 800`，`text-transform: none`，`clamp(2.4rem, 6.6vw, 5.4rem)`，`line-height: 1.02`，`letter-spacing: -0.035em`。
- **超大数字**：`--sans`，`800`，可以大到 `clamp(4rem, 14vw, 12rem)`，作为**背景装饰**用。
- **表格与所有数字**：`--mono`，`font-variant-numeric: tabular-nums`。
- **微标签**：`--mono`，11px，`uppercase`，`letter-spacing: .16em`。
- **圆角：0**。这一版没有曲线。

- 三条色带都是**通栏满宽**（`width: 100vw` 的块，用 `margin-inline: calc(50% - 50vw)` 技巧），彼此硬边相接，**无间隙、无圆角**。
- 白色带里 H1 左对齐，右边距收窄；群青带里副标题压窄到 `min(560px, 92%)`。
- 群青带右侧/背景里放一个**超大的数字 `144`**（`#FFFFFF`，`opacity: .08`，`font-weight: 800`，`position: absolute`，`overflow: hidden` 裁切，`aria-hidden="true"`）。让数字"藏在字母后面"呼应线索。
- 品红带上放表单：输入框是白底、0 圆角、1px 深色边框；按钮是深色底 + 白字。
- 最下方一条**常驻走马灯数据条**：群青更深一档的底（`#1A1AA0`），`--mono` 小字，内容循环横向滚动，项之间用 `◆` 分隔。内容取自产品事实（144 格 / 6 格每小时 / 已排 39 格 / 空 105 格 / 本周完成率 82% 等），可用 CSS 动画实现，`prefers-reduced-motion` 下静止。

## 「144 格」装置（D 的画法：**表格 / 账页**）

在首屏走马灯下方放一块**账页**：

- 144 格做成 **24 行 × 6 列**的表格（每行一小时，6 格 = 每小时 6 格，呼应 `6 CELLS / HOUR`）。
  窄屏退化为 **6 列仍然保留**，但格子缩小（`aspect-ratio` 控制，避免溢出）。
- 每一行左侧有一个等宽行号/时刻标签（`00` `01` … `23`）。24 行太多时可以在移动端只显示时刻每 6 行一次并压缩行高（**必须保证不横向溢出**）。
- 格子状态用颜色区分，并在表格上方给出**图例**（等宽小字 + 色块）：
  - 已排期 = 品红 `#FF2E8B`
  - 已完成 = 白 `#FFFFFF`
  - 空 = 群青 + 1px `#7FE6FF` 描边（`opacity .5`）
- 表格用 `border-collapse: collapse`，单元格 1px `#7FE6FF`（`opacity .35`），**硬边、无圆角**。
- 表格下方一行汇总（等宽，右对齐）：`已排 39 格 · 已完成 21 格 · 空 84 格 · 合计 144 格`。
  这一行是 D 的签名 —— **合计必须等于 144**。

## 各区块的处理（顺序不可变）

1. **导航**：群青底，单行。左 wordmark（白，粗）；中间锚点链接（等宽小字，白，hover 时品红底白字/深字）；右品红底深字 CTA（硬边 0 圆角）。
   ≤820px 收成汉堡（品红方块按钮），展开面板是群青整宽面板，项与项之间 1px `#7FE6FF` 线。
2. **主视觉**：见上。
3. **快速录入演示**：做成**一张三列的表单式对照表**（像一张三联单据）：
   - 表头行：`01 输入` / `02 解析` / `03 排期`，白字，底为 `#1A1AA0`，1px `#7FE6FF` 边框。
   - 第 1 列：等宽原句，等宽字体，白字。
   - 第 2 列：三行 key-value 表（`截止` / `项目` / `预计`），value 用等宽数字；底部一行品红底深字标签 `占 3 格`。
   - 第 3 列：`今天 15:00–15:30` 用大号等宽白字，下面 `与现有安排不冲突` + 冰蓝对勾。
   - 窄屏时三列变三层堆叠，保留边框与表头样式。
4. **社会证明**：一行四家公司名，**等宽大写**，白字，之间用 `◆` 分隔，上下各一条 1px 冰蓝线。上方微标签 `IN USE AT`。
5. **功能**：**横向三点轨道** —— 一条 1px 冰蓝横线串起三个节点，每个节点是一个品红实心小方块（不是圆点），
   下方是微标签 `01/02/03` + 标题 + 说明。三栏等宽。
6. **工作流程**：**横向四栏**，栏间用冰蓝竖线 + 箭头（用 CSS 边框或内联 SVG 箭头），每栏顶部一个**大号等宽数字** `01`–`04`（白色，`opacity` 高）。
7. **用户评价**：三张**等宽卡片**并排，白底（纸白 `#F2EDE4`）+ 深色字 + 0 圆角，卡片顶部一条 6px 品红边。署名用等宽小字，职务用淡紫——不，**卡片内是深色字，职务用 `#5A5A8A`**（保证在白底上可读）。
8. **价格**：**一张真正的对照表**（`<table>` 语义或 grid 模拟）：
   - 左列是特性名，右两列是免费版 / Pro，用 `✓` / `—` 表示。
   - 表头行底为 `#1A1AA0`；Pro 列整列用白色底 + 深色字反白突出（与其他列形成强对比）。
   - 月付/年付切换是两个硬边方块按钮，选中项品红底深字，未选中项透明 + 1px 冰蓝边框。
   - 年付时切换旁出现 `省 20%` 标签；Pro 价格显示 `¥32/月`。
9. **常见问题**：**编号列表**，每条左侧一条 4px 品红竖线贯穿，`<details>`，`summary` 前是等宽编号 `01`–`06`，右侧 `+`/`−`。
10. **页脚**：三栏：左品牌 + 一句话（白）、中间产品链接、右侧法务链接；上方一条 1px 冰蓝线；底部一条极小的等宽版权行。

## 动效

- 数字**滚动/翻牌**：进入视口时，汇总行里的数字从 0 快速计到目标值（`700ms`，`requestAnimationFrame` 或 CSS steps；`prefers-reduced-motion` 下直接显示终值）。
- 走马灯循环滚动。
- 表格行 hover：底变 `#1A1AA0`。
- 按钮 hover：品红块位移 `translate(-2px,-2px)` 并出现 2px 深色硬阴影（`box-shadow: 2px 2px 0 #0A0A24`），`120ms`。**这是 D 唯一允许的"软"效果，且必须是硬阴影，不是模糊阴影。**
- `prefers-reduced-motion: reduce`：关闭走马灯与计数动画。

## 明确不要做的事

- **不要深色底**（底色必须是大面积群青），不要霓虹发光，不要毛玻璃。
- 不要圆角（全站 0），不要模糊阴影。
- 不要点阵网格（A）、不要大字留白（B）、不要居中镜像对称（C）。
- 品红不要当小字放在群青上（对比度不够）。
