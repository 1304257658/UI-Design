# 案例 A · 观测台（Observatory）

> 认领的线索：**144 = 12×12，一天 = 144 个十分钟格**。
> 立场：时间不是感觉，是**可以被测量的东西**。把格子做成一台仪器。

一句话：如果排期引擎是一台天文台，落地页就该是它的仪表盘。

## 定位

技术精密、克制、昂贵感。像一块瑞士手表或一台射电望远镜的控制面板：
近黑的冷色底，极细的 1px 线，极少量但极准的琥珀色光。
访客应该觉得"这东西真的在计算"。

**不要**做成常见的"深色 SaaS 模板"（紫蓝渐变 + 玻璃拟态卡片 + 发光大按钮）。
这里的深色是**仪器外壳**，不是赛博霓虹。

## 色板（精确使用，不得随意加色）

| 角色 | 值 | 说明 |
| --- | --- | --- |
| 页面底 | `#0A0F16` | 夜蓝黑，全站唯一底色 |
| 面 | `#101822` | 区块面 / 卡片 |
| 抬升面 | `#16202C` | 需要再抬一层时 |
| 线 | `#1E2A36` | 1px 分隔线、格子描边 |
| 线（强） | `#2C3B4A` | 需要强调的边框 |
| 正文 | `#E9EEF4` | 对比度 ≈16:1 |
| 次级文字 | `#8A9AAB` | 对比度 ≈6.4:1，只用于说明性文字 |
| 强调（琥珀） | `#F2A93B` | 已排期 / 主 CTA / 关键数字。对比度 ≈8.6:1 |
| 强调（青） | `#45C6D6` | 解析态 / 链接 / 次要数据 |
| 琥珀上的字 | `#0A0F16` | 实心琥珀按钮的文字 |

规则：**琥珀是稀缺资源**。一屏之内琥珀色的面积不应超过 5%。
青色只用来表示"正在被解析/计算"的状态。除此之外不再引入任何颜色。

## 字体

```
--sans: "Inter", "Segoe UI Variable Display", "Segoe UI", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
--mono: ui-monospace, "Cascadia Mono", "SF Mono", "JetBrains Mono", "Songti SC", Consolas, monospace;
```

- **H1 / 区块标题**：`--sans`，`font-weight: 600`，`letter-spacing: -0.02em`，中文不要用超粗。
- **数字、时间、格子编号、标签、按钮**：`--mono`，`font-variant-numeric: tabular-nums`。
- **微标签**：`--mono`，11–12px，`text-transform: uppercase`，`letter-spacing: .12em`，色 `#8A9AAB`。
- 字号只用 `clamp()` 定义在 `:root` 上，例如
  `--fs-h1: clamp(2.1rem, 5.2vw, 4.4rem)`、`--fs-h2: clamp(1.5rem, 3vw, 2.4rem)`、
  `--fs-body: clamp(0.95rem, 1.05vw, 1.05rem)`。

## 首屏构图（必须与其他三个案例明显不同）

**左右不对称，右侧是一整块仪器盘。**

```
┌──────────────────────────────────────────────────────────┐
│ 十分 TENTH     功能 流程 价格 常见问题        [免费开始]  │
├──────────────────────────────────────────────────────────┤
│                                        ┌───────────────┐ │
│ 10 MIN GRID · 144 CELLS                │  仪器盘        │ │
│                                        │  12 × 12 点阵  │ │
│ 一天 144 格，                          │  已排格亮起    │ │
│ 你想留下什么                           │  扫过一条光带  │ │
│                                        │               │ │
│ 随手记一句，十分自动找出时间、          │  00:00 → 24:00│ │
│ 项目与时长，把它放进今天               └───────────────┘ │
│ 最合适的那一格。                                        │
│                                                          │
│ [ your@email.com        ] [ 免费开始 ]                   │
│ 无需信用卡，30 秒就能排好今天                            │
└──────────────────────────────────────────────────────────┘
```

- 左栏宽度约 `min(520px, 46%)`，`position: sticky`，`top` 留出导航高度。
- 右侧仪器盘是一块 `#101822` 面，1px 边框，**内部是 12×12 = 144 个格子**（CSS grid，非 SVG）。
  - 每个格子约 `aspect-ratio: 1`，圆角 2px，默认 `background:#16202C`。
  - 约 20–28 个格子是"已排期"：`background:#F2A93B`，`opacity` 在 .5–.9 之间随机但**固定**（不要用 JS 随机跳动）。
  - 约 6–10 个格子是"解析中"：`#45C6D6`。
  - 其余为空。
  - 整个盘上叠一层极淡的 1px 网格线（`background-image: linear-gradient(...)` 双向）。
- 仪器盘底部一行等宽小字：`00:00 — 24:00 · 6 CELLS / HOUR · 144 / DAY`。
- 背景：`body` 上一层固定的极淡网格（1px 线，`opacity: .35`，色 `#1E2A36`），四周用 `radial-gradient` 渐隐掉。

## 各区块的处理（顺序不可变）

1. **导航**：单行。左 wordmark（`十分` + 等宽小字 `TENTH`）/ 中间锚点链接（等宽、小号、hover 时出现琥珀色下划线）/ 右实心琥珀 CTA。
   ≤820px 收成汉堡，展开面板是**从顶部拉下的整宽面板**，不是居中弹窗。
2. **主视觉**：见上。
3. **快速录入演示**：做成**三段串联的信号流**，横向三栏，栏间用 `▸` 或细线连接：
   - 栏 1「输入」：等宽字体显示 `周五前把课程大纲发给陈老师 #课程 @30分钟`，放在一个带 1px 边框的暗色输入条里，右侧有一个闪烁光标（`prefers-reduced-motion` 下不闪）。
   - 栏 2「解析」：三行 key-value（截止 / 项目 / 预计），key 是等宽小标签，value 是正文色数字；底部一行琥珀色 `占 3 格`。
   - 栏 3「排期」：显示一条 6 格的小刻度条，`15:00–15:30` 高亮琥珀，下面是「与现有安排不冲突」+ 一个对勾图标（内联 SVG）。
   - 每栏顶部有等宽编号 `01 / 02 / 03`。
4. **社会证明**：一行等距四家公司名，等宽字体，`#8A9AAB`，之间用发丝竖线分隔。上方一行微标签 `IN USE AT`。
5. **功能**：一大两小。左侧主功能占约 60%，右侧两个次要功能上下堆叠。
   每个功能块：微标签 + 标题 + 说明 + **一个极简内联 SVG 图形**（线稿风格，`stroke:#45C6D6`，`fill:none`，`stroke-width:1.5`）。
6. **工作流程**：四步，做**粘性左侧刻度尺**装置 —— 左栏粘着一条从 `00:00` 到 `24:00` 的竖刻度尺，右侧四步依次滚过，滚到时左侧刻度尺上的指示器移动到对应时刻（用 `IntersectionObserver` + `transform`，尊重 reduced-motion）。
7. **用户评价**：纵向堆叠三条，每条左侧一个等宽大引号 `"`，整体左对齐，条目之间一条 1px 线。
8. **价格**：整宽两行堆叠，做成**清单式对照表**（不是卡片）。每行左侧档位名、中间特性、右侧价格。Pro 行用 `#16202C` 底 + 左侧 3px 琥珀条标出。月付/年付切换放在区块标题右侧，是一个**等宽分段控件**（`role="group"` + 两个 `button`）。
9. **常见问题**：左右两栏各三条，栏间一条竖线。`<details>`，`summary` 右侧一个 `+` / `–`（用 CSS 旋转，不要用字符图标以外的东西）。
10. **页脚**：单行：左品牌 / 右链接，上方一条 1px 线。

## 动效

- 进入视口的元素：`opacity 0→1` + `translateY(10px→0)`，`220ms`，`cubic-bezier(.2,.7,.2,1)`。
- 仪器盘的格子：加载时**依次点亮**（`transition-delay` 按索引递增，总时长不超过 900ms）。
- 一条极淡的横向扫描光带缓慢扫过仪器盘（8s 循环，`opacity .06`）。
- **`prefers-reduced-motion: reduce` 下**：关闭扫描光带、格子依次点亮、光标闪烁、指示器移动，全部只保留即时状态。

## 明确不要做的事

- 不要紫色/蓝色霓虹渐变，不要玻璃拟态，不要发光大阴影。
- 不要大圆角（圆角上限 3px）。
- 不要用点阵以外的网格画法（这是 A 的专利）。
- 不要做成"三个等宽卡片 + 居中标题"的通用 SaaS 版式 —— 首屏必须是不对称双栏。
