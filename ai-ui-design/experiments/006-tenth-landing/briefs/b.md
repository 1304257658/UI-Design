# 案例 B · 留白（The Void）

> 认领的线索：全串**唯一重复的两个字符是 `00`**，而且有 **8 个字符一次都没出现过**。
> 立场：空缺不是缺陷，是**还没被占用的资产**。

一句话：一个效率应用最难说的那句话是"这周有三件事你别做"。

## 定位

纸白、极简、编辑排版、近乎静止。像一本昂贵杂志的跨页，或者一张画廊墙签。
用**大得不得了的留白**来表达"少做一点"。整页的信息密度刻意做得极低，
每一屏只讲一件事，靠巨大的垂直节奏推进。

**不要**做成"浅色卡片网格"的常规落地页。这里没有卡片、没有阴影、没有圆角、没有按钮底色。

## 色板

| 角色 | 值 | 说明 |
| --- | --- | --- |
| 纸 | `#F5F3EE` | 全站唯一底色，暖白 |
| 纸（次） | `#EDEAE3` | 极少用，仅在需要一层"纸"时 |
| 正文 | `#0D0D0C` | 对比度 ≈18:1 |
| 次级文字 | `#5E5A52` | 对比度 ≈5.6:1 |
| 细线 | `#DAD6CC` | 1px 规则线 |
| 强调（信号红） | `#D93A1E` | 只用于图形与 ≥18px 的文字 |
| 强调（深红） | `#B62E14` | 小字号需要红色时用这个 |

规则：**红色一页最多出现 3 次**。它必须像印刷套印偏了一版那样刺眼、稀少。
除此之外全站无彩色。

## 字体

```
--serif: "Source Han Serif SC", "Noto Serif SC", "Songti SC", "SimSun", Georgia, "Times New Roman", serif;
--sans: "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", system-ui, sans-serif;
--mono: ui-monospace, "Cascadia Mono", "SF Mono", Consolas, monospace;
```

- **H1**：`--serif`，`font-weight: 600`，**极大**，`clamp(2.6rem, 7.5vw, 6rem)`，`line-height: 1.12`，`letter-spacing: -0.01em`。
- **区块标题**：`--serif`，`clamp(1.6rem, 3.4vw, 2.8rem)`。
- **正文**：`--sans`，`clamp(0.95rem, 1.05vw, 1.1rem)`，`line-height: 1.85`（很长，制造从容感）。
- **注释 / 编号 / 图注**：`--mono`，11px，`letter-spacing: .14em`，`text-transform: uppercase`，色 `#5E5A52`。
- 字距普遍偏松（正文 `letter-spacing: .01em`），中文行高偏大。

## 首屏构图（必须与其他三个案例明显不同）

**上三分之一一行大字，其余全空。**

```
│                                                          │

│   你想留下什么                                           │
│                                                          │

│                                                          │
│   随手记一句，十分自动找出时间、项目与时长，              │
│   把它放进今天最合适的那一格。                            │

│                                                          │

│   your@email.com ______________________   免费开始 →      │   ← 无框，只有一条下划线
│   无需信用卡，30 秒就能排好今天                           │

│                                                          │
│                                    143 格空着。            │   ← 右下角一行等宽小字
└──────────────────────────────────────────────────────────┘
```

- 首屏整体高度至少 `92vh`，内容集中在**上 60%**，下方留出大片真正空的纸面。
- 右下角一行等宽小字 `143 格空着。`（这是 B 的签名，红色或 `#5E5A52`）。
  这正是"留白"立场的宣言。
- 表单：`input` 无边框、无背景，只有底部 1px 线（`#DAD6CC`，focus 时变 `#0D0D0C`）；
  按钮是**纯文字 + 箭头**，没有底色，hover 时箭头右移 4px。
- 导航：没有任何分隔线以外的装饰，wordmark 用 `--serif`。

## 「144 格」装置（B 的画法：**空即是内容**）

在首屏正下方放一条**极安静的 144 格带**：

- 144 个格子排成 **1 行或 2 行**（移动端 2 行），每格 `1fr`，高约 18–26px，格子之间 2px 间隙。
- **143 格是没有填充的**，只有 1px `#DAD6CC` 描边；
- **只有 1 格是实心 `#0D0D0C`**（代表"今天真正重要的一件事"）。
- 格子带上方一行等宽注释：`一天 144 格 · 空着的 143 格才是你的余量`；
- 格子带下方一条 1px 线收尾。
- 这一块**不加任何动效**（或只在进入视口时整体淡入一次）。

## 各区块的处理（顺序不可变）

1. **导航**：单行，无背景色，只有一条 1px 底线。锚点链接是 `--mono` 小字。≤820px 收成汉堡，展开面板也是纸面、无阴影，靠 1px 线分区。
2. **主视觉**：见上。
3. **快速录入演示**：**三段纵向**，像三条印刷校样：
   - 每条左侧是等宽小标签 `INPUT` / `PARSE` / `SCHEDULE`，右侧是内容，条目之间用 1px 线分隔。
   - 输入条：等宽字体，无框，前置一个 `>`。
   - 解析结果：三行，key 用等宽小字，value 用衬线稍大。
   - 排期：`今天 15:00–15:30` 用衬线大字，下方小字「与现有安排不冲突」。
   - 三段之间用巨大的垂直留白（`clamp(48px, 8vw, 120px)`）隔开，不要做成紧凑卡片。
4. **社会证明**：一行四家公司名，`--serif`，之间用 `·` 分隔，居中或左对齐均可，上下各留大量空白。上方一行等宽 `TRUSTED BY`。
5. **功能**：**不并列**。三块功能纵向排开，每块占一整屏的舒适高度：
   左侧大号衬线序号 `01 02 03`，右侧标题 + 说明；块与块之间一条 1px 线。
   每块配一个**极简线稿内联 SVG**（`stroke:#0D0D0C`，`fill:none`，`stroke-width:1`），体积要小、要安静。
6. **工作流程**：四步做成**编号目录**（像书的目录页）：左编号 / 中标题 / 右说明，行高极大，行间 1px 线。不要做成带圆点的流程条。
7. **用户评价**：三条纵向，每条是一段大号衬线引文（`clamp(1.15rem, 2vw, 1.6rem)`），署名在下一行用等宽小字。不要卡片、不要引号图标，用中文引号「」即可。
8. **价格**：不做卡片。做成**一排对齐的文字**：
   - 两栏，左「免费版 ¥0」右「Pro ¥40/月」；特性用 `·` 分隔的列表，行高宽松。
   - Pro 那一栏的标题用信号红，并在其上方加一条 2px 红线。除此外无任何装饰。
   - 月付/年付切换：两个**下划线式文字按钮**，当前项下方有 1px 实线。
   - 年付时按钮旁标注「省 20%」。
9. **常见问题**：**单窄栏**（最大宽度约 `62ch`），只用 `1px` 横线分隔的 `<details>` 列表。`summary` 右侧是一个等宽的 `+`，打开时旋转 45°。
10. **页脚**：居中，`--serif` 大字 `十分 Tenth` 在上，链接一行在下，版权用等宽小字在最底。上方一条 1px 线。

## 动效

- **几乎不动**。只做一件事：元素进入视口时 `opacity 0→1`，`400ms`，不加位移。
- 链接 hover 时箭头位移 4px；`summary` 的 `+` 旋转 180ms。
- 没有视差、没有滚动动画、没有悬浮卡片。
- `prefers-reduced-motion: reduce` 下全部即时。

## 明确不要做的事

- **不要卡片**：没有 `border-radius`（全站 0）、没有 `box-shadow`、没有色块容器。
- 不要按钮底色，不要渐变，不要图标库风格的多色图标。
- 不要点阵网格（那是 A 的专利），不要表格（那是 D 的专利）。
- 不要把留白填满 —— 如果一屏看起来很"充实"，就是做错了。
