同一个产品，同一份文案，四种设计语言

这四张落地页讲的是同一个产品（十分 Tenth：把一天切成 144 个十分钟格子）， 用的是逐字相同的文案、相同的区块顺序、相同的交互要求。 唯一变化的是视觉语言与版式结构 —— 这样横向比较才成立。

四个方向的灵感来自一条 144 位随机字符串。它本身不出现在任何一张设计稿里， 只用来推导配色、布局与字体。量出来的事实如下：

144字符串长度 = 12 × 12，完全平方数
0.1144 分钟 ÷ 1440 分钟 = 一天的十分之一
144 格一天 24 小时 ÷ 10 分钟 = 144 格
27 / 117数字 27 个（3³）藏在 117 个字母里，10 个数字一个不少
54 / 62只有 54 种字符出现，8 种一次都没出现
00全串唯一重复的相邻字符，是两个零
72正中心在索引 72，前后两半几乎共用同一套字符
0 / 72镜像对称位置命中 0 处 —— 它完全不对称

A

观测台 · Observatory

时间是可以被测量的东西。把 144 格做成一台仪器：夜蓝黑外壳、发丝线、琥珀色只用在"已经排上"的地方。

线索：144 = 12×12打开整页 →深色 · 等宽 · 3px 圆角
B

留白 · The Void

空着的格子才是资产。纸白、巨大衬线、一页只讲一件事；全站没有一张卡片，红色只出现三次。

线索：唯一的 00、8 个缺席字符打开整页 →浅色 · 衬线 · 0 圆角
C

中轴 · Axis

完全对称不存在，但人可以站回中间。暖砂纸、一条贯穿全页的竖轴、镜像格带里故意留两处错位。

线索：正中心 72 / 镜像 0-72打开整页 →暖浅色 · 人文 · 14px 圆角
D

台账 · Ledger

每一格都要对上账。印在群青纸上的一张对账海报：硬边色带、超大数字、24×6 的格子账页。

线索：117 字母藏 27 个数字打开整页 →饱和群青 · 表格 · 0 圆角

怎么验证

四个文件都是单文件、零外部依赖，双击即可打开。静态检查与浏览器实测：
node scripts/serve.mjs → 打开 http://127.0.0.1:8781/
node scripts/audit.mjs（含种子泄漏检查）
node scripts/measure.mjs（360/768/1024/1440 溢出与交互实测 + 截图）

四张页面共用的硬要求

单文件零外链 · 表单内联校验且不用 alert() · 价格切换后只剩一个数字 · <details> 手风琴 · ≤820px 汉堡导航带 aria-expanded · 锚点全部有落点 · 360/768/1024/1440 无横向溢出 · 尊重 prefers-reduced-motion。

比较时建议盯住三件事

一、首屏能不能在没有文案帮助的情况下说清"这是个什么工具"。 二、同一个「144 格」装置，四种画法里哪一种让"一天是有边界的"这件事最有体感。 三、把文字换成你自己产品的文案之后，哪一套骨骼还站得住。
