## GPU 修正与证据

原脚本虽将 Cycles 路径追踪设为 GPU / OptiX，但 OpenImageDenoise 的 `denoising_use_gpu` 默认为 false；CPU 降噪是本次确认的一个 CPU 计算环节。没有据此声称旧渲染的所有阶段都在 GPU 执行。

现显式使用 OptiX 渲染和 OptiX GPU 降噪，仅启用 RTX 4090 D 的 OptiX 设备；找不到该设备则报错，禁止静默回退。实际补帧期间 `nvidia-smi` 采样多次达到 94%—95% GPU 占用，Python 渲染进程在 GPU 进程列表中。记录 `gpu-samples.txt`、`build-seat-gpu.log`、`build-sequence-gpu.log`、`build-home-gpu.log`。

完整 241 帧已用统一 GPU 路径重新生成，座垫线迹贴合修正也覆盖整段。场景建模、文件写入和 WebP 压缩仍使用 CPU。没有将整机 GPU 占用率描述为单个进程的精确利用率。

当前仅本地预览，没有公网部署或移动端验收。造型剩余差异包括侧缝曲线、扶手形态及织物颗粒；隐藏结构为补建。
