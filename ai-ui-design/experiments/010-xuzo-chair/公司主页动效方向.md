# 公司主页 · 家具与内容的连续切换

本版使用固定镜头、家具正面展示、独立水平文案。已替换之前的房间聚合方案。

| 章节 | 家具动作 | 公司内容 |
| --- | --- | --- |
| 序作 | 桌、椅、沙发、灯分布在视野周围 | 让舒适，成为日常 |
| 关于我们 | 桌子进入中央，桌面转向镜头；其他家具退出 | 品牌定位、家具与空间设计 |
| 设计方法 | 桌面保留，小幅等比推进 | 观察、推敲、体会 |
| 舒适理念 | 桌子退出，椅背正面进入中央 | 对身体、姿态与感受的关照 |
| 共同愿景 | 椅子退出，沙发正面进入中央 | 松弛、相聚与舒适日常 |

文字先退、家具交接、文字后入。所有文字由 HTML 排版，不随家具旋转。相机全程固定在 (0,0,20)，没有自由观察功能。

初始椅子模型和其热点可打开 /products/contour-01/。其余家具没有产品跳转；导航及页面底部保留普通产品入口。

实现文件：src/furniture-scene.js、src/home.js、src/home.css。统一规范：DESIGN.md。桌子使用 Poly Haven 的现代茶几模型，椅子使用既有 Blender 模型，沙发与落地灯独立建模。具体来源见 references/结构与素材来源.md。

已用本地 Chrome 验证四种桌面尺寸、双向滚动、章节定点、固定相机、产品跳转、咨询窗口、减少动态效果以及资源失败时的文字降级。证据位于 evidence/furniture-v3/browser-qa.json；仅代表本地验证，没有公网部署。
