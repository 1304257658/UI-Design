# 从源码运行与离线交付

这是源码学习仓库，不附带 `dist`、`node_modules` 或便携 Node.js。

Windows 首次运行：安装 Node.js 24 LTS（含 npm），双击本目录的「启动」脚本。脚本检测环境，在没有 dist 时执行 `npm ci`、`npm run build`，随后启动预览；缺少环境会给出安装地址，不会静默安装软件。首次安装依赖需要网络，预览不需要 Blender。

修改源码后手工运行 `npm run build`；启动脚本不会覆盖已有构建。开发调试使用 `npm run dev`。跨平台可执行 `npm ci`、`npm run build`、`node preview.mjs`。

预览服务只监听 127.0.0.1。端口占用会尝试后续端口，不终止别人的进程；以控制台实际 URL 为准。按 Ctrl+C 停止。`检查运行环境.cmd` 检查构建及运行环境，不安装依赖。

给无环境的 Windows x64 电脑离线展示：在开发电脑构建，另备可信来源的 Node.js 便携包，将 node.exe、官方许可证和校验值放入 runtime/（node.sha256 为 node.exe 的 SHA-256）。再运行 `打包部署.cmd`。部署包目录和便携程序均被 Git 忽略。目标电脑完整解压后可运行；没有便携程序时需要系统 Node.js 18+。自行准备的运行时与离线包需要再做启动验证，本次 Git 迁移未交付二进制运行环境。

序作以站点根路径部署，不能直接放到任意 URL 子目录或 file:// 打开。公网部署、后台接入、移动端不在本次验收范围。
