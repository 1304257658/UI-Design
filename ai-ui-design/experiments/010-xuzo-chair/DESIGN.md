# 序作 · 统一视觉与动效规范

本规范是公司主页与产品页的共同依据。产品页已采用暖象牙白、深石墨绿正文与灰橄榄绿交互色。

## v7 清晰度与阅读（优先于下方历史方案）

固定产品的相机、构图与轨迹，仅将桌面正文向右收近至 20vw。正文和局部特写保持独立留白；小桌面下缩短属性分隔线，避免靠近座垫。前台移除章节条、计数、步骤序号及演示跳转。测试版本选择器保留在独立 `/review/` 页面。

提高实际渲染分辨率与采样，织纹尺度以全景可辨、近景不过粗为准；接缝为连续细暗线和同色针脚，不能用平面锐化掩盖形体问题。首页椅子同步同一模型、织物和灯光。

## v6 产品材质与造型（优先于下方历史方案）

产品选择 A：鼠尾草绿织物与香槟金属。以批准概念图的连续包裹椅背、中央缝线、厚软包座垫、弯折且顶部展开的扶手为造型依据。可见比例参照原图校准，隐藏结构为本案例补全，不宣称单图模型是精确工程复制。

网页保持左文右物和六章构图；椅背、座面和扶手分别特写，最后重组。Blender Cycles 渲染 241 帧，Canvas 等比显示；画面边缘只延展空摄影棚背景，椅子本身不拉伸。正文覆盖独立暖白阅读底层，避免材质透入文字。章节与当前实际绘制帧同步。

公司主页唯一产品入口同步使用同一 Blender 模型的透明渲染。首页持续漂浮、家具退场与品牌内容结构保持 v5 方案。具体来源和完整生成提示词见 references/contour-sage.md。

## v5 当前构图与动效（优先于下方历史方案）

首屏六件家具围绕中央横排文案，采用倒置桌子、侧翻柜子与茶几、斜置灯具、沙发和人体工学椅。暖象牙白、橄榄织物、自然木纹、石墨框架和克制金属高光保持统一。为阅读和交互留出轮廓间距；与批准图相比移除了花瓶、书本等松散道具，避免倒置时产生不合理的附着。

家具为六个透明 WebP 图层。首屏停留期间持续沿闭合轨迹漂移：各件周期分别为 12–19 秒，水平往返约 12–18px、垂直约 18–25px、转角约 2.2–4 度，起始相位与旋转方向错开。这是持续无限循环，不是一次入场动作。属于 2.5D 合成，不模拟绕三维轴转身。滚动通过外层预设向外轨迹驱动，内层保持漂浮，家具保持不透明，完全离开后暂停动画。正文独立 HTML 横排，始终处在空出的阅读区域。

人体工学椅是首页唯一产品入口：hover/focus 显示提示、轻微抬升和柔和投影，滚动离场时取消点击。公司内容继续主导后续页面，不再使用底部产品推广卡片。减少动态效果时关闭自动漂浮、取消滚动缓动和悬停位移。

桌面验证见 design-qa.md。产品页继续原有三维拆解，后续改版沿用本规范色彩与字体。

## v4 历史构图与动效

开场使用固定镜头 Cycles 家具向外退场序列，独立且不透明的公司介绍版面逐步展开。生活场景、材料细节和设计方法共同支撑公司介绍。正文保持横排，不透出家具，不使用残影消散。

舒适理念为固定双栏，通过滚动切换身体、触感、空间；照片裁切显露，保持原有比例。设计方法配草图与样件；愿景用深橄榄色 #303F31 收束。理念区使用浅灰绿 #E2E4D8，整体延续暖象牙白、橄榄绿和自然木色。

开场绿色休闲椅属于场景氛围资产，不冒充人体工学椅。产品通过导航与末尾入口进入独立子页。本轮验证尺寸为 1280×720、1440×900、1920×1080，没有移动端验收。

以下材质、文字和品牌配色继续有效；家具逐件转正承载内容的早期方案已由上述版式替代。

## 品牌表达

围绕「让舒适，成为日常」展开。用桌子讲人与空间的关系，用椅子讲身体的承托，用沙发讲松弛与相聚。公司主页介绍品牌、方法、理念和愿景；零件拆解与功能特写放在产品子页。

## 材质与构图

材质以实物纹理为优先：木材、织物、哑光聚合物、适量金属。保留真实反射、织纹、缝边、结构连接与圆角。模型不使用透明残影、粒子消散或拉伸缩放；缩放始终等比。

公司主页采用固定正交镜头。家具从画面周围进入中心，旋转至适合阅读的正面姿态。桌面法线朝向镜头；椅背与沙发靠背以正面承接视觉。文案是独立 HTML 图层，停留时水平可选中，不能烘焙在模型上。

## 动效规则

初始：家具环绕，品牌居中。只有人体工学椅有产品热点及实体点击入口。

转场：旧文案退出 → 当前家具向画面外漂移，同时下一件家具入场并转正 → 家具稳定后出现新文案。设计方法继续使用桌面，只做微幅等比推进。反向滚动沿同一时间线复原。

用户仅通过页面滚动与章节导航控制进度，没有自由相机。停止滚动并收敛后停止重绘。系统减少动态效果设置启用时使用固定章节姿态。

桌面验证尺寸：1280×720、1440×900、1920×1080、2560×1080。本次没有移动端适配。
