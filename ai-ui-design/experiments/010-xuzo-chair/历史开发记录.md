## 技术与模型

- Blender 5.1 Python API 离线建模，保存 `.blend` 并导出 GLB。
- Three.js / WebGL 实时加载、材质、摄影棚反射和阴影。
- GSAP 的暂停时间线由页面滚动进度驱动，镜头和部件共同变化。
- 模型为六个独立总成、30 个材质网格，约 11 万三角面；静止后停止逐帧重绘。
- 网布是带透明织纹的曲面材质，区别于椅身的哑光聚合物、金属支脚和软触面。
- 模型加载失败或图形上下文丢失时，显示由真实场景捕获的静态备用图，并缩短展示区。

模型是参考真实椅子结构制作的展示设计，不是原厂 CAD、认证产品或制造图纸；爆炸布局用于介绍总成关系，不是维修步骤。没有拆开气压杆内部。尺寸、功能、寿命和健康效果未作为量产产品性能进行宣称。

## 公司主页：三维空间叙事版

根路径为公司主页，产品页位于 `/products/contour-01/`。

1. 空间初现：空场地等待家具进入。
2. 公司介绍：桌、椅、沙发、茶几、落地灯、收纳柜、绿植与背景构件错峰进入，聚成完整空间。
3. 舒适理念：家具重新排布，镜头换位，讲自在、体贴与长久。
4. 设计方法：周围物品实体退出画面，桌面与材料样本保留，镜头靠近。
5. 公司愿景：所有家具回到完整空间，镜头拉远，接到产品入口与咨询。

主场景由 Three.js 实时渲染，GSAP 暂停时间线由页面滚动进度驱动。物品以独立总成做位置与朝向变化，不使用图片窗口变形或淡出替代退出动作。没有自由相机控制。停止滚动后，场景停止逐帧重绘；反向滚动沿同一时间线返回。

桌、灯、沙发、茶几、绿植、柜子、墙面与空间构件为本案例代码建模，椅子复用本案例已有 Blender GLB。木纹、织物与接触阴影为程序纹理，摄影棚 HDR 与字体沿用现有授权素材。这是展示用空间模型，不是施工或家具制造图纸。

- `src/room-scene.js`：三维模型、材质、灯光、镜头及聚合/退场时间线。
- `src/home.js`：滚动映射、章节与场景加载。
- `src/home-contact.js`：本机咨询内容整理与复制。
- `src/home.css`、根目录 `index.html`：公司主页内容和排版。
- `evidence/space-v2/qa.json`：当前三维版本验收。
- `evidence/space-v2/空间聚合与退场.webm`：实际浏览器滚动录屏。

此前图片窗口版本的说明与截图不代表本版。公司品牌、理念与愿景仍是演示设定，不编造经营数据、资质与联系方式。咨询窗口仅在本机整理、复制内容，不发送或保存。
