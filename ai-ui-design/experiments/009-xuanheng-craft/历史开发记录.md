# 玄衡自动化 · 工业自动化系统集成

换电脑运行：双击「启动零件制作.cmd」，会自动检查并使用随包便携 Node.js，无需安装开发环境。复制范围、端口处理和离线部署见 [部署说明](部署说明.md)。

基于「03-xuanheng-homepage」品牌与业务方向制作的独立官网案例。本版通过滚动驱动预设镜头，展示机床、加工、设备退场与成品细节，再进入公司介绍。当前仅以桌面 Web 为工作和验收范围，暂停手机适配。

## 打开成品

双击「预览官网.cmd」，或运行 `node preview.mjs`，打开 http://127.0.0.1:3197 。需要 Node.js；预览直接使用随包提供的 `dist`，无需安装依赖。

向下滚动观看，向上滚动沿原路线返回。底部六个章节按钮可以跳转；镜头、刀具和夹具都跟随页面进度，没有自由旋转或独立缩放。

## 六幕内容

1. **机床全貌**：封闭式机床外罩、观察门、控制台与内部转台。
2. **进入加工区**：门打开，镜头进入，门在加工前关闭；样件保持夹持。
3. **加工过程**：主轴进给、退刀、转台分度与第二次进给；镜头从多个方向观察。
4. **制作完成**：刀具先退开，夹具松开；外罩、主轴、转台和底座以实体位移退出视角，成品留在中央。没有透明淡出、残影、粒子或溶解。
5. **成品巡游**：表面、五个螺纹孔、键槽、倒角以及背部台阶；前后视角沿零件外侧绕行。
6. **公司主页**：从样件过渡到企业介绍、核心业务、工程能力、服务支持与业务咨询。

画面采用石墨色背景、银灰金属、少量橙色标记，以及本地 Manrope / 思源黑体。机床为分组建模，静态部件合并以减少绘制调用；镜头停稳后停止重绘。本轮重做了钣金边缘、导轨、折板、紧固件和线缆，区分喷涂外壳、拉丝钢板与切削铝件；加入真实摄影棚 HDR 反射环境和 GTAO 接触阴影。3D 加载失败时显示桌面静态备用图，并缩短展示区。既有移动规则保留，但不属于本轮更新和验收范围。

## 参考与边界

- 零件外观参考：[ROD International — Aluminum CNC Machined Wheel Hub](https://rodintl.com/products/aluminum-cnc-machined-wheel-hub)。五孔法兰、锥形凸台和带键槽的通孔按实物照片比例重建。
- 机床结构参考：[Haas UMC-500](https://www.haascnc.com/machines/vertical-mills/universal-machine/models/umc-500.html)。方形外部结构是防护罩；实际工作台、夹具和工件位于内部。
- 外罩功能参考：[Haas Enclosure](https://www.haascnc.com/productivity/product-options/enclosure.html)；加工关门参考：[UMC Safety](https://www.haascnc.com/service/online-operator-s-manuals/umc-series-operator-s-manual-supplement/umc---safety.html)。

环境光来自 [Poly Haven Studio Small 09](https://polyhaven.com/a/studio_small_09)，作者 Sergej Majboroda，CC0 授权，记录见 `public/licenses/Poly-Haven.txt`。环境图仅供照明和反射；加载失败时仍可使用内置照明。

这是实时 Three.js 官网展示。参考照片与生成式分镜仅用于设计研究；页面不使用厂商照片、生成式分镜或录制视频替代 3D 场景。实际页面的材质与形体以浏览器截图和运行结果为准，生成式分镜不是页面效果证明。

没有取得样件 CAD、制造图纸或经验证的实际工艺路线。零件及设备是按参考重建的展示模型，刀具动作和设备退场是叙事编排，不是可执行加工程序；退场也不表示真实机床会拆解。未声明参考厂商与玄衡存在合作关系。

玄衡沿用原案例的虚构公司设定。官网已完成本地实现，未部署公网。咨询资料功能只在浏览器生成文本文件，不向外发送，不接入真实业务后台。

## 修改与构建

```powershell
npm ci
npm run dev
npm run build
```

Node.js 24、Vite 8、Three.js。`src/machine.js` 管理机床，`src/assembly.js` 管理样件，`src/timeline.js` 编排加工动作，`src/scene.js` 编排镜头及渲染；文案在 `index.html`。静态产物位于 `dist`，资源路径相对化。授权文件见 `public/licenses`。

本次内容与可读性验收结果及实际截图位于 `evidence/company-v5`，验收范围见 `evidence/验收说明.md`。旧版证据保留在本地上级目录，不代表本版结果。
