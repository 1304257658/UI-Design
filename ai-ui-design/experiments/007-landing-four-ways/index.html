受控内容对照 · 四个视觉方向

Flowtide 落地页：同一份内容，四种设计方向

文案、区块顺序、功能全部固定（见 CONTENT-SPEC.md），四个案例只改变视觉语言与版式结构。这样比较的是设计方向，而不是文案运气。

  • A · QUIET TECHNICAL

    A · 安静的技术极简

    近黑底、克制灰阶、细描边与单一冷色强调，表单做成贯穿全宽的命令行。传达精密与可信。

    打开案例 A →
  • B · WARM EDITORIAL

    B · 温暖编辑排版

    奶油纸底、大号衬线标题、栏线与不对称双栏。像一篇认真排过的长文，耐读、有分量。

    打开案例 B →
  • C · FRIENDLY CONSUMER

    C · 亲切大众消费向

    高饱和亮色、大圆角、柔和彩色投影与插画式图形。降低门槛，让非技术用户愿意试。

    打开案例 C →
  • D · BOLD TYPOGRAPHIC

    D · 大胆字体海报感

    粗黑描边、硬阴影偏移、超大标题分层色块与高对比撞色。视觉冲击优先，记忆点足。

    打开案例 D →
四个案例都实现了同一套功能，可以逐项对比体验差异：
  • 邮箱表单内联校验（不弹 alert）
  • 月付 / 年付切换，Pro 同一时刻只显示一个价格数字
  • <details> 手风琴 FAQ
  • ≤820px 汉堡导航，带 aria-expanded，关闭态不可被键盘 Tab 进
  • 360 / 768 / 1024 / 1440px 无横向溢出、无内容被裁切
