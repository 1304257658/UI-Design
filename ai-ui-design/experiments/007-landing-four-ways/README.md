# Flowtide 落地页 · 四个视觉方向

同一份受控内容（见 [CONTENT-SPEC.md](./CONTENT-SPEC.md)），四种互不靠近的视觉语言。用来回答：**在文案、区块顺序、功能完全固定的前提下，设计方向能拉开多大差距？**

| 案例 | 方向 | 文件 |
| --- | --- | --- |
| A | 安静的技术极简（深色） | [cases/a.html](./cases/a.html) |
| B | 温暖编辑排版（浅色衬线） | [cases/b.html](./cases/b.html) |
| C | 亲切大众消费向（圆润高饱和） | [cases/c.html](./cases/c.html) |
| D | 大胆字体海报感（高对比） | [cases/d.html](./cases/d.html) |

四个文件都是单文件、零外部依赖，双击即可打开；每个页面右下角有 A/B/C/D 切换器，可直接横向对比。

## 怎么跑

```powershell
cd H:\Project\UI-Design\ai-ui-design\experiments\007-landing-four-ways
python -m http.server 8773 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8773/](http://127.0.0.1:8773/)。

## 四个方向的差异点

| | A 技术极简 | B 编辑排版 | C 亲切消费 | D 字体海报 |
| --- | --- | --- | --- | --- |
| 底色 | 近黑 #08090B | 奶油 #FBF7F0 | 暖白 #FFF9F3 | 亮黄 #FFE14D |
| 字体 | 无衬线 + 等宽细节 | 衬线标题 + 无衬线正文 | 无衬线加粗 | 无衬线 900 |
| 圆角 | 8–12px | 0–2px | 16–28px | 0 |
| 描边/阴影 | 1px 低对比描边 | 1px 栏线 | 柔和彩色投影 | 3px 粗描边 + 硬阴影 |
| 首屏构图 | 顶部大字左对齐 + 命令行式通栏表单 | 不对称双栏：左索引 + 竖栏线 + 右大标题 | 上图下文：插画画布 + 居中标题 | 层叠色块海报，H1 拆三行压在色块上 |
| 功能/流程 | 细线分栏 + 等宽编号 | 编号栏线编辑式列表 / 三栏表格 | 圆角卡 + 彩色图标底座 / 软色大编号 | 粗描边方块 + 大号贴纸编号 |
| 评价 | 纵向堆叠，左侧超大引号 | 书评式大引言 + 署名 | 字母头像 + 五星 | 描边卡 + 方形字母块 |

## 自检

```powershell
node scripts/verify.mjs     # 静态检查 + 无头 Chrome 实测（需先起 8773 服务）
node scripts/shots.mjs      # 分段截图 → evidence/crops/（便于人工看图）
```

`verify.mjs` 覆盖：单文件零外链、标签/CSS/JS 括号平衡、锚点与 aria 引用、必需交互与关键文案、脆弱 vw 用法，以及在 360/768/1024/1440 四个宽度实测：

- 横向溢出（以**设备宽度**为准，不看 `innerWidth`——移动端"缩小适配"会假报 0 溢出）
- 布局视口被撑宽（shrink-to-fit）
- 内容被父级裁掉（`overflow:hidden/clip` 把文字切一半，页面没有滚动条所以很难发现）
- 邮箱校验三态、月付/年付价格数字、FAQ、汉堡开合与**关闭态是否仍可被键盘 Tab 到**

当前结果：静态 0 问题、运行时 0 问题。截图见 `evidence/screens/`（整页）与 `evidence/crops/`（分段）。
